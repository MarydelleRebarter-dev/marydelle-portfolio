# Marydelle D. Rebarter — Portfolio

A responsive Next.js portfolio inspired by the supplied dashboard/clinic UI reference, redesigned for an Information Technology student.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository in Vercel.
3. Vercel detects Next.js automatically.
4. Build command: `next build` (or leave the default).
5. Output settings can stay at their defaults.

## Customize

Edit `app/page.js` for content and `app/globals.css` for colors, spacing, and layout.

The profile area currently uses initials (`MR`) because no profile photo was supplied. Replace it with an image later if desired.
